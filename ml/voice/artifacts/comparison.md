# Tone model comparison

Same speaker-independent split; test set of 2048 windows from speakers none of the models heard. Each model gets the input that suits it, its own settings search on the validation speakers, the same calibration, and its own anger-alert rule chosen on validation (at most 1% false alarms). Ordered by speech-only macro-F1. Generated by `python -m voice.compare report`.
