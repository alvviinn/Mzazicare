# MzaziCare first-aid assistant (caretakers)

A caretaker types what is happening, in English, Kiswahili or a mix ("bibi ameanguka bafuni", "he is choking"),
and gets clear first-aid steps. It runs entirely on our own server: no outside AI service, no message is stored.

## Design: understand with a model, advise only from a vetted guide

The assistant does **not** generate advice with a language model. A generative model can sound confident while
inventing wrong steps, which is dangerous in first aid. Instead:

1. **The guide** (`knowledge/*.md`): 43 first-aid topics written from published guidance (IFRC International First
   Aid, Resuscitation and Education Guidelines 2020, ILCOR/AHA CPR guidance, Red Cross and St John Ambulance manuals,
   WHO), focused on elderly care in Kenya (falls, skin tears, pressure sores, low sugar, charcoal-jiko fumes, snake and
   dog bites, Kenyan emergency numbers 999 / 112 / Red Cross 1199). Each topic has: when to call for help, numbered
   steps, what not to do, what to do after, and for some a follow-up question with buttons (e.g. "Is the person
   breathing normally?"). Every topic is in English and Kiswahili. `python -m firstaid.knowledge` checks it (both
   languages complete, follow-ups point to real topics, life-threatening topics say "call 999").
2. **The question model**: a pretrained multilingual language model (`intfloat/multilingual-e5-small`, 118 M
   parameters, already knows English and Kiswahili) **fine-tuned end to end** to recognise which of the 43 topics a
   message is about, or that it is a greeting, a general health question, or not about first aid.
3. **The safety check**: danger words in both languages ("not breathing", "hapumui", "chest pain", "damu nyingi",
   "degedege", every keyword of every life-threatening topic) always put "Call 999 or 112 now" at the top of the reply,
   whatever the model says.
4. **"Did you mean?" instead of guessing**: below a confidence threshold (chosen on validation so that at least 95 % of
   the answers given are right), the assistant offers its three best topics as buttons. If any of them is
   life-threatening it also says how to get help now.
5. **Natural replies**: a short calm opener, the urgent line, an explanation, numbered steps, "do not" points, the
   after-care line and the follow-up question, in the language the caretaker wrote in (or chose).

## Data (all public, plus our own)
| Source | Used as | Size used |
|---|---|---|
| Hand-written examples in the guide | how people ask about each topic (English, Kiswahili, mixed) | 498, expanded to ~12k realistic variations (typos, code-switching, urgent wording, different people) |
| FirstAidQA (CC BY 4.0), first-aid Q&A sets on Hugging Face (alexxxmf, lextale, belvisk, Baddoub, adv010, badri55), symptom-triage conversations | real first-aid questions, labelled with the guide's keywords (kept only when exactly one topic matches; a hand check of 80 found 94 % right, the loose keywords were then tightened) | 7,073 labelled |
| MedQuAD (via lextale) | general health questions that are not first aid | 16k available, 4k used |
| CLINC150 (CC BY 3.0) | everyday requests and small talk (not first aid) | 23k |
| Amazon MASSIVE (CC BY 4.0) | everyday requests in **English and Kiswahili** (sw-KE) | 33k (test partition untouched) |

Rejected after inspection: "FirstAid-Treatment IT" (71k items): its prompts are scrambled document chunks with
mismatched topics, so training on it would teach mistakes.

Splits: validation never shares a hand-written example (or its variations), a public dataset or a dataset partition
with training. **The test set** (`eval/test_questions.tsv`, 197 messages) was written separately, before any model was
trained, in the style of real caretaker messages, and is used once at the end. Training data: 38,568; validation 11,430.

## Limits you should know about
* **It is not a doctor.** It recognises the situation and shows vetted first-aid steps; it does not diagnose. Every
  reply says so, and the Call 999 button is always on screen.
* **The Kiswahili text and examples were written by the developer** and must be reviewed by a native-speaking
  first-aid trainer (e.g. Kenya Red Cross) before real use. The same goes for the guide's medical content: it follows
  published guidelines but has not yet been signed off by a clinician.
* The test set is small (197) and written by the developer, so its figures show the method works, not field
  performance. Real caretaker messages (with consent) are the next test.
* Topics outside the 43 get "did you mean" or "not first aid" replies rather than advice.

## Commands (run from the `ml` folder, ML venv)
```
python -m firstaid.get_data        # download the public datasets (~120 MB) to C:\mzazicare-data\firstaid\raw
python -m firstaid.knowledge       # check the guide, write artifacts/guide.json
python -m firstaid.data            # build train/val/test
python -m firstaid.train baseline  # TF-IDF + logistic regression
python -m firstaid.train frozen    # pretrained sentence vectors + logistic regression
python -m firstaid.train finetune  # fine-tune multilingual-e5-small (about 4 hours on an 8-core CPU)
python -m firstaid.export          # 8-bit ONNX + tokenizer + threshold -> artifacts/
python -m firstaid.evaluate        # compare all models on the test set -> artifacts/comparison.md
python -m unittest discover -s firstaid/tests -t .
```
